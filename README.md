<h1>馬レボリューション (UmaRevolution) </h1>

<p>Bienvenue sur le repo de 馬レボリューション, une application web en PHP permettant de rentrer un score et d'obtenir le personne si le score est > au précédent.</p><br>
<p>Ce site internet est privé et à destination de la communauté 馬レボリューション (UmaRevolution)</p><br>

<p>Les comptes utilisateurs sont ajoutés manuellement dans la base de donnée.</p>
